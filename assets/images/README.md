# Images Directory

Place your project screenshots and profile photos here:

- `profile.jpg` or `profile.png` - Real portrait or developer avatar for the Hero and About sections.
- `project-1.jpg`, `project-2.jpg`, `project-3.jpg` - Featured project mockups or screenshots.

The portfolio is designed with elegant SVG visual placeholders out-of-the-box. When you are ready to use real photos, simply replace the placeholder containers in `index.html` or update the image paths in `js/script.js`.
